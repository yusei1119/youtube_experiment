# 実験後アンケートの入力データ

Google FormsからCSVを再取得したときは、このフォルダの対応ファイルを更新します。

- `実験後アンケート_ex1_...csv`: 90分版（A系）
- `実験後アンケート_ex2_...csv`: 60分版（B系）

更新後、リポジトリ直下で `python run_analysis.py` を実行すると、CSVの
スナップショットを保存してから全分析を行います。

分析結果のCSVを直接修正しても次回の再分析には反映されません。実験上の補正は
入力CSVへ反映し、変更理由を `data/corrections/README.md` に記録してください。
