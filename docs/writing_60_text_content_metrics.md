# Writing task 60：回答本文の内容指標

## 1. 目的

Writing task 60の自由記述回答から、視聴時間による文章表現の変化を定量化する。
文字数や記述時間だけでなく、語彙の多様さ、内容語の密度、因果的な説明、内省的な
表現、具体性、文の長さを評価対象とする。

これらは文章の表面的・言語的特徴を再現可能な方法で測る**代理指標**である。
回答の正しさ、映像内容の理解度、実際に視聴した動画との意味的整合性、文章の総合的な
良し悪しを自動採点するものではない。

## 2. 分析単位

各参加者は次の5カテゴリに1回答ずつ記述する。

1. `general`: 一般的な問い
2. `content`: 映像内容
3. `inquiry`: 映像から生じる問い
4. `emotion`: 感情・内面の変化
5. `summary`: 映像の要約

本文指標は最初に質問単位で算出する。その後、各指標について参加者内の5回答を
単純平均し、参加者単位の分析値を作る。したがって、長い回答だけが参加者スコアを
支配せず、5カテゴリを同じ重みで扱う。

## 3. 日本語テキストの前処理

形態素解析には[Janome](https://janome.mocobeta.dev/ja/)を使用する。Janomeは
MeCab IPADICを内包するPure Pythonの日本語形態素解析器であり、表層形、基本形、
品詞などを返す。

処理手順は次のとおり。

1. 回答の先頭・末尾の空白を除去する。
2. Janomeで形態素へ分割する。
3. `記号`、`フィラー`、`その他`の品詞を分析対象形態素から除外する。
4. 活用語は可能な限り基本形へ変換する。
5. 名詞、動詞、形容詞、副詞を「内容語」とする。
6. 文の境界は `。`、`！`、`？`、`!`、`?` の連続で判定する。

空回答または分析可能な形態素がない回答は欠測値とする。

## 4. 質問別指標

### 4.1 内容語数

- 出力列: `content_word_count`
- 参加者別5問平均: `Mean_content_word_count`
- 単位: 語／回答

名詞、動詞、形容詞、副詞の合計数である。

\[
\text{内容語数}=N_{noun}+N_{verb}+N_{adjective}+N_{adverb}
\]

値が大きいほど、1回答に含まれる実質的な語の量が多い。ただし、既存の回答文字数と
強く相関しやすいため、内容の質ではなく「実質語による記述量」と解釈する。

### 4.2 語彙多様性（MATTR）

- 出力列: `lexical_diversity_mattr`
- 参加者別5問平均: `Mean_lexical_diversity_mattr`
- 範囲: 0以上1以下
- 窓幅: 内容語20語

内容語の基本形列に対してMoving-Average Type–Token Ratio（MATTR）を算出する。
各20語窓の異なり語数を20で割り、全窓を平均する。

\[
\mathrm{MATTR}_{20}
=\frac{1}{N-20+1}\sum_{i=1}^{N-20+1}
\frac{|\mathrm{unique}(w_i,\ldots,w_{i+19})|}{20}
\]

内容語が20語以下の場合は、回答全体の異なり内容語数を内容語数で割る通常のTTRを
使用する。

値が1に近いほど、同じ内容語の反復が少なく、語彙が多様である。MATTRは単純なTTR
より文章長の影響を抑えるために用いる。ただし短い回答では窓を十分に移動できず、
通常のTTRになる点に注意する。MATTRの原典は
[Covington & McFall (2010)](https://doi.org/10.1080/09296171003643098)である。

### 4.3 内容語比率

- 出力列: `content_word_ratio`
- 参加者別5問平均: `Mean_content_word_ratio`
- 範囲: 0以上1以下

記号等を除いた全形態素に占める内容語の割合である。

\[
\text{内容語比率}=\frac{N_{content}}{N_{all\ tokens}}
\]

値が大きいほど、助詞・助動詞などの機能語に対して内容語が多い。情報密度の代理として
扱うが、日本語では文体や文法構造の影響も受けるため、単独で文章の質を判断しない。

### 4.4 因果・精緻化表現率

- 出力列: `causal_marker_rate`
- 参加者別5問平均: `Mean_causal_marker_rate`
- 単位: 出現数／100形態素

理由、原因、結果、影響などを明示する表現の出現数を、回答の形態素数で標準化する。

\[
\text{因果表現率}=\frac{N_{causal\ markers}}{N_{all\ tokens}}\times100
\]

複合表現として次を数える。

- `なぜなら`
- `そのため`
- `だから`
- `したがって`
- `ゆえに`
- `からこそ`
- `ことによって`

さらに、基本形が次に一致する形態素を数える。

- `結果`
- `理由`
- `原因`
- `影響`
- `きっかけ`

値が大きいほど、因果関係や説明のつながりを明示する傾向が強い。ただし辞書にない
因果表現は検出できず、同じ単語でも文脈によっては因果を示さない場合がある。

### 4.5 内省表現率

- 出力列: `reflection_marker_rate`
- 参加者別5問平均: `Mean_reflection_marker_rate`
- 単位: 出現数／100形態素

思考、感情、自己言及、認識の変化に関係する基本形の出現数を、回答の形態素数で
標準化する。

\[
\text{内省表現率}=\frac{N_{reflective\ markers}}{N_{all\ tokens}}\times100
\]

対象とする基本形は次のとおり。

- 思考・認識: `思う`、`感じる`、`考える`、`気づく`、`気付く`、`理解`、`捉える`
- 視点・価値: `見方`、`価値観`
- 自己・内面: `自分`、`私`、`心`、`感情`、`印象`
- 問い: `疑問`、`問い`

値が大きいほど、自己の思考・感情・認識を明示する傾向が強い。ただし質問文自体が
感情や問いを要求するため、質問カテゴリおよび質問variantの影響を受ける。

### 4.6 具体性マーカー率

- 出力列: `specificity_marker_rate`
- 参加者別5問平均: `Mean_specificity_marker_rate`
- 単位: 出現数／100形態素

次のマーカーを具体的な対象・数量・明示された語句の代理として数える。

- Janomeが`名詞,固有名詞`と判定した形態素
- Janomeが`名詞,数`と判定した形態素
- `「…」`または`『…』`で囲まれた1～30文字の語句

\[
\text{具体性率}=\frac{N_{proper}+N_{number}+N_{quoted}}{N_{all\ tokens}}\times100
\]

値が大きいほど、固有名、数値、明示的に括られた語句を使う傾向が強い。ただし一般名詞
による具体的な描写は検出できない。また、引用内の固有名詞や数は複数のマーカーとして
数えられる場合がある。

### 4.7 1文あたり形態素数

- 出力列: `sentence_length_tokens`
- 参加者別5問平均: `Mean_sentence_length_tokens`
- 単位: 形態素／文

記号等を除いた形態素数を、句点・感嘆符・疑問符で区切った文数で割る。

\[
\text{文長}=\frac{N_{all\ tokens}}{N_{sentences}}
\]

値が大きいほど、一つの文に多くの形態素を含む。構文的な精緻さの一側面になり得るが、
句読点を使わない癖でも大きくなるため、「長いほど良い」とは解釈しない。

## 5. 視聴時間の検定

### 5.1 質問variantの調整

各カテゴリには3種類の質問variantがある。質問文の難易度や誘導の違いを軽減するため、
傾向検定では質問IDごとに指標の平均を中心化する。

質問 \(q\) に対する参加者 \(i\) の値を \(y_{iq}\)、質問ID別平均を
\(\bar{y}_q\)、全質問の平均を \(\bar{y}\) とすると、調整値は次になる。

\[
y^{adj}_{iq}=y_{iq}-\bar{y}_q+\bar{y}
\]

この調整値を参加者内で5問平均して傾向検定に使う。これは質問variantの加法的な平均差を
調整する方法であり、variantと視聴時間の交互作用まではモデル化しない。

### 5.2 順序傾向検定

視聴時間を `5min=1`、`10min=2`、…、`30min=6` とする順序変数へ変換し、
調整済み5問平均とのSpearman順位相関係数 \(\rho\) を算出する。

p値は視聴時間ラベルを9,999回並べ替える両側置換検定で求める。乱数seedの既定値は42で
あり、同じ入力とseedでは同じ結果になる。

本文7指標は同じデータから探索するため、7個のp値を一つのファミリーとしてHolm法で
補正する。主な判断には`p_holm_across_text_metrics`を使う。

変化量の解釈を補助するため、Theil–Sen法による5分増加あたりの傾きと95%信頼区間も
出力する。この信頼区間自体は多重比較補正されていない。

### 5.3 6群比較と事後比較

5、10、15、20、25、30分の6群について、各指標を次の手順で比較する。

1. 群内残差のShapiro–Wilk検定とLevene検定を確認する。
2. 正規性と等分散性を満たす場合は一元配置ANOVAを使う。
3. それ以外はKruskal–Wallis検定を使う。
4. 全群の値が同一なら統計量0、p値1とする。
5. 15通りの事後比較を行い、各指標内でHolm補正する。

ANOVAの効果量はη²、Kruskal–Wallisの効果量はε²である。事後比較は分布に応じて
Welchのt検定またはMann–WhitneyのU検定を使う。

### 5.4 質問カテゴリ別の探索

5カテゴリそれぞれについて7指標の順序傾向を調べる。合計35検定のp値を一つの
ファミリーとしてHolm補正する。この分析は、5問平均で相殺されるカテゴリ固有の変化を
探すための探索的分析である。

## 7. 解釈上の注意

- 有意でない結果は「差が存在しない」ことの証明ではない。
- 本分析は各視聴時間群8～13名程度であり、小さい効果の検出力は限定される。
- 辞書ベース指標は、辞書に含まれない言い換えや文脈上の意味を扱えない。
- Janomeの分割・品詞推定が常に正しいとは限らない。
- 質問variantの中心化は平均差のみを調整し、すべての質問文効果を除去するものではない。
- 文章の正しさ、映像との関連性、解釈の深さを評価する場合は、視聴時間を伏せた複数評価者
  によるルーブリック採点と評価者間一致度の検討が必要である。
